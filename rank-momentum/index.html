PERCENTRANK 함수 (기둥 ①·③ 공통)

pct = (값보다 낮은 종목 수) / (유효 종목 수 − 1) × 100

기둥 ① 순위모멘텀

  • 4/12/25/52주 수익률 각각 PERCENTRANK → mom_score = 단순 평균
  • 수익률 기준일: 캘린더 역산 (4w = 기준일 − 28일, 휴장이면 직전 거래일)

기둥 ③ 가격모멘텀

  • gap_52w_high = (기준일 종가 − 52주 고점) / 52주 고점 × 100
  • price_score = PERCENTRANK(gap_52w_high 전체)

합산

combined = (2 × mom_score + price_score) / 3

기준일 모드

히스토리 파일(15개월 종가)에서 해당 날짜의 종가로 수익률·순위·점수 전체 재계산. 스마트머니·PER·섹터는 현재 값 유지.

ref_price  = closes[ticker][snap(refDate)]
target_4w  = last close <= refDate − 28d
ret_4w     = (ref_price − target_price) / target_price × 100
