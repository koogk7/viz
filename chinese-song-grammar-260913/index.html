像是中了你的毒
Xiàng shì zhòng le nǐ de dú
"네 독에 중독된 것 같아" — GINGER

① 像是 + 中了…的毒 — 비유 + 이산 구조

像是 + 中了 + [대상] + 的毒
像是(xiàng shì) = ~인 것 같다 (비유·감각 강조, 好像보다 문어적)
中 = zhòng 4성 "맞다·당하다" — zhōng(가운데 1성)와 구분
中毒·中奖·中枪 모두 같은 4성 zhòng 계열
了 = 상태 변화 완료("이미 그렇게 됐다")
像是中了这首歌的毒。이 노래에 중독된 것 같아.
비교
好像 ≈ 像是好像=구어 추측 / 像是=비유 감각 강조

② V不住 — 가능보어 부정 ★핵심

动词 + 不住 (= "~할 수 없다")
住 = 결과를 붙잡아 두다. 不住 = 그 상태 유지 불가.
긍정: 动词 + 得住
藏不住 cáng bu zhù감출 수 없다 ↔ 藏得住 감출 수 있다
忍不住 rěn bu zhù참을 수 없다
记不住 jì bu zhù외울 수 없다
留不住 liú bu zhù붙잡을 수 없다
다른 예
那种感觉忍不住，根本停不下来。그 감각은 참을 수 없어, 멈출 수조차 없어.

③ 把자문 — 목적어 전치

把 + 대상 + 동사(+결과보어)
목적어를 앞으로 당겨 "~을 어떻게 처리하다" 강조. 처분·결과 초점.
把自己贡献给…자신을 ~에 바치다
다른 예
把心里的话说出来。마음속 말을 꺼내다.

④ 明明 — "분명히 ~인데도"

明明 + 사실 + 却/还是 + 역접
뻔히 알면서도, 분명한데도 — 역접 강조. 뒤에 却·还是·也와 짝.
明明知道，还是…뻔히 알면서도, 그래도…
다른 예
明明很累，还是睡不着。분명 피곤한데 잠이 안 와.

⑤ 让 사역 — "나를 ~하게 하다"

让 + 사람 + 동사
让 = 허락·사역. "누군가가 나를 ~하게 만들다".
让我身处…나를 ~에 처하게 하다
다른 예
这首歌让我忍不住哭。이 노래가 나를 울지 않을 수 없게 해.

⑥ 着 — 지속상

동사 + 着 (了=완료와 대비)
了 = 완료(끝난 시점) vs 着 = 지속(상태가 이어짐).
隐藏着 yǐncáng zhe숨기고 있다·숨긴 채로
等着 děng zhe기다리고 있다
다른 예
他看着我，没说话。그가 나를 바라보며 말하지 않았다.

⑦ 没…过 — 경험 부정

没 + 动词 + 过 (= ~해본 적 없다)
过 = 경험 상태보어. 没+V+过 = 그 경험이 없음.
没看过 méi kàn guò본 적이 없다
다른 예
我没去过台湾。（现在去过了！）대만에 가본 적이 없었다. (이제 다녀왔다!)

⑧ 동량보어 — 횟수 표현

动词 + 횟수 + 遍/次/下
遍(biàn) = 처음부터 끝까지 완주 1회
次(cì) = 단순 횟수   下(xià) = 가볍게 한 번
七遍 qī biàn일곱 번 (완주)
다른 예
这首歌我听了三遍。이 노래를 세 번 들었다. (완전히)

⑨ 说…也不算… — 양보 구문

说 + 형용사 + 也不算 + 형용사
"~다고 해도 그렇게 ~한 건 아니야" — 역접 양보.
说多也不算多많다고 해도 그렇게 많은 건 아니야
다른 예
说贵也不算太贵。비싸다고 해도 그리 비싼 건 아니야.

⑩ 양사 중첩 一道一道

一 + 양사 + 一 + 양사 (= 하나하나·연속)
양사 중첩 = 하나하나·연속·많음 뉘앙스. 시각적 반복 이미지 강조.
一道一道 yī dào yī dào한 줄기 한 줄기
一步一步 yī bù yī bù한 걸음 한 걸음
다른 예
一步一步地走向你。한 걸음씩 너에게로 걸어간다.

⑪ 变+형용사 / 了 변화

变 + 형용사 | 동사 + 了
变+adj = ~하게 변하다   V+了 = ~해졌다 (변화 완료)
变炙热 biàn zhìrè불타듯 뜨거워지다
停滞了 tíngzhì le정체됐다
乱了 luàn le뒤엉켜버렸다
다른 예
天气变冷了。날씨가 추워졌다.
